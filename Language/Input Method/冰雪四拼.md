# 重复 技巧

## 完整重复

==单音节== 吃 吃
        A  A
        yi _[_
        yi_i_
        
==双音节== 尝试 尝试
        A B  A B  
        y vi _A_（`若用 [ 则会取 尝 这个字`）
        
==三音节== 顶一下 顶一下
        A B C  A B C  
        d f xu _A_（`若用 [ 则会取 顶 这个字`）

==四音节== 及以上 _A_ 是 大写，是顶功。
