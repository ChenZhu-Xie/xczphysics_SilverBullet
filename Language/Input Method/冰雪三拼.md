## 笔bku画hq

键道不同于大字根形码（如小鹤音形把“禾”作为一个整体键位 `h`），它采用 **5元音键（`v, i, u, o, a`）小字根/笔画体系**：

> **note** Note
> 可以视为 将 声笔系列 aeuio 中的 横 e 改到了 v，其他没有区别

| 首码  | 笔画/单码根 | 双码根 |
| --- | --- | --- |
| `v` | 一、木 | **土/士 `vo`** |
| `i` | 丨、人 | 艹 `ii`、手 `iu`、金 `io` |
| `u` | 丿、月 | 十 `uo` |
| `o` | 丶、口 | 日 `oi` |
| `a` | 折、水 | 贝 `ao` |

因此：

*   左侧 **“禾”** 拆为：首笔撇（`丿` $\\to$ `u`）+ 次笔横（`一` $\\to$ `v`）= **`uv`**
*   右侧 **“失”** 拆为：首笔撇（`丿` $\\to$ `u`）+ 次笔横（`一` $\\to$ `v`）= **`uv`**
*   合并形码即为 **`uvuv`**。

### 快捷键

*   `Ctrl + .`：固定 / 取消固定当前选中的候选词
*   `Ctrl + [`：将选中的候选词向前移动一位
*   `Ctrl + ]`：将选中的候选词向后移动一位
*   `Ctrl + \`：重置当前编码下的自定义候选 *(如果在 iOS 仓输入法等移动端皮肤中，长按候选词弹出的菜单里也有对应的“加词”、“固定”、“前移”、“后移”、“重置”)*
*   `Ctrl + ,`：缓冲造词
*   `Ctrl + l`：光标 移到 第 2 码后

### 补充：如何删除自造词

输入编码看到自造词时，将高亮光标移到该候选上，按下：

*   **`Shift + Delete`**（部分系统/键盘下为 **`Ctrl + Shift + Delete`**）
*   或方案内置快捷键 **`Ctrl + k`**

即可将该词从自造词库中删除。
